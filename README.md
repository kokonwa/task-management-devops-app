# 🚀 DevOps Task Management App

A full-stack task management application deployed on AWS using modern DevOps practices.

---

## 🌐 Live Demo

https://dh2s8bspdnbz9.cloudfront.net

---

## 🛠️ Tech Stack

### Frontend

* React (Vite)
* TypeScript

### Backend

* Flask (Python)
* SQLite

### Cloud & DevOps

* AWS EC2 (Backend Hosting)
* AWS S3 (Frontend Hosting)
* AWS CloudFront (CDN Distribution)
* Environment Variables (Production Configuration)
* CORS Configuration

---

## ⚙️ Features

* User Authentication (Login)
* Task Management (Create, Update, Delete)
* Dashboard with task categories (To Do, In Progress, Done)

---

## 🚀 Deployment Process

* Built frontend using Vite
* Deployed backend API on AWS EC2
* Hosted frontend static files on AWS S3
* Configured AWS CloudFront for global content delivery
* Connected frontend to backend via API endpoint

---

## 🐛 Challenges & Fixes

* Fixed "Failed to fetch" API errors (CORS configuration)
* Resolved HTTP vs HTTPS conflict between frontend and backend
* Fixed 404 errors in CloudFront using SPA routing configuration
* Debugged API endpoint connectivity issues

* Real-world DevOps deployment troubleshooting
* AWS cloud services configuration (EC2, S3, CloudFront)
* Frontend and backend integration in production
